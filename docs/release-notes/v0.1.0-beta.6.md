# Rift Gun 0.1.0-beta.6 — Minecraft 26.1.2

- Released: 2026-08-17
- Previous: none (first release of the 26.1.2 platform port)
- Platform: Minecraft 26.1.2, NeoForge 26.1.2.95+, Java 25
- Artifact: `riftgun-26.1.2-0.1.0-beta.6.jar`

Beta: same feature set as the 1.21.1 build, but the platform port is new
and has seen less real-world testing. A known cosmetic rendering issue
remains (see Known issues).

## Changes since the 1.21.1 beta.5 line

### New platform: Minecraft 26.1.2

- Full port of the shared codebase to Minecraft 26.1.2 / NeoForge
  26.1.2.95: new render-pipeline rendering, per-version NBT seams, recipe
  and datapack registration, chunk-ticket handling, client GUI and
  resources.

### Fixes

- Fix portal chunk tickets targeting the wrong chunk (`ChunkPos`
  block/coordinate mix-up) in the portal entity and relocation
  preparation — teleports to never-loaded destinations now proceed.
- Let transit proceed while a distant exit chunk is still loading; open
  portal clocks immediately so distant exits work.
- Restore the post-transit `hasImpulse` flag semantics on the 1.21.1 side
  of the shared transit pipeline.
- Fix a relocation reservation leak on out-of-bounds destinations.
- Fix destination selection: creating a destination while a player target
  was selected kept opening portals to the player.
- Restore typed NBT presence checks on save-data loading.
- Reject out-of-bounds portal placements, destinations, chunk tickets and
  relocation exits with a clear message.
- Server and client boot cleanly with a clean datapack reload; bucket and
  key assets, special recipe codecs and the enchanted-book ingredient
  restored.
- Double background draw fixed; player-list request guarded when
  disconnected.
- JEI on 26.1.2: the JEI bridge is back (fluid-transmutation category),
  the custom crafting recipes (advanced basic module, zero point fuel
  module, and the eternal-duration chain) are shown in JEI and the recipe
  book with correct grid slots, and the fluid transmutation recipes sync
  to clients in multiplayer.

### Additions

- Action-bar reason when a transit is refused: portal exit blocked, or
  exit portal not ready.
- Out-of-bounds destination notifications.

### Build / tooling

- Gradle 9.7 + ModDevGradle, Stonecutter 0.9.7 multi-version layout,
  per-node JDK and version properties, CI version-matrix builds.

## Known issues

- A faint light rim can appear around the portal surface (cosmetic; under
  investigation).
- RyoamicLights integration is not yet available on this platform.
- Shader-pack appearance uses a conservative fallback and may vary.

## Upgrading

Back up worlds before updating. Player destinations and privacy
preferences are stored as server-side player data; visual preferences are
client-local.
