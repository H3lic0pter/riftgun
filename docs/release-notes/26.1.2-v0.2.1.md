# Rift Gun 0.2.1 — Minecraft 26.1.2

- Previous: 0.2.0-rc.1
- Platform: Minecraft 26.1.2, NeoForge 26.1.2.95+, Java 25
- Artifact: `riftgun-26.1.2-v0.2.1.jar`
- Public Addon API: `1.2.0` (unchanged)

## Highlights

- Automatic Search now saves a reusable target in the Random section. Searching
  starts when the target is used, instead of immediately opening a portal.
- Automatic targets support pinning and deletion, with persisted section
  expansion state. Editing, moving to another group, and sharing are unavailable.
- Cancel stale requests when a target changes, is deleted, or its player leaves.
- Recheck authorization and fuel during deferred preparation and final opening.
- Clean up both members of a closed paired portal instead of leaving a stale
  partner entity behind.
- Keep original dimension text out of routine client snapshots while preserving
  server-side saved data and text-target identity.

## Upgrade Notes

Back up worlds, player data, and configuration before upgrading. Replace the old
mod JAR, and install the same `0.2.1` build on the server and all clients.
Do not install the `-api` or `-api-sources` artifacts in `mods`; those are for
addon developers.

Player data schema advances from 10 to 11. Existing exact-coordinate targets
retain their coordinates. Restore a pre-upgrade backup when rolling back;
older builds do not understand the new deferred target semantics.

## Platform Limitations

- Infinite Dimensions text-based generation is **not available** on 26.1.2.
  This release provides saved Automatic Search targets for existing dimensions.
- Create and Immersive Portals integrations remain specific to the 1.21.1 build.
- Placement remains non-destructive: obstructed or unavailable destinations may
  fail instead of modifying blocks.
- In-game smoke testing remains recommended before deployment. Other optional
  integration limitations from 0.2.0-rc.1 continue to apply.
