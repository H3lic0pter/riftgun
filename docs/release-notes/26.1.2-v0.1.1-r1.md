# Rift Gun 0.1.1-r1 — Minecraft 26.1.2

- Released: 2026-08-23
- Previous: 0.1.0-beta.6
- Platform: Minecraft 26.1.2, NeoForge 26.1.2.95+, Java 25
- Artifact: `riftgun-26.1.2-v0.1.1-r1.jar`

Rift Gun 0.1.1-r1 is a polish and compatibility release for Minecraft 26.1.2,
focused on rendering improvements, Immersive Portals visual compatibility, and
stability fixes after the initial 26.1.2 platform port.

This release continues the multi-version codebase introduced in 0.1.0-rc.1,
with Minecraft 26.1.2 maintained alongside 1.21.1 from the same shared codebase.

## Highlights

- Added optional Immersive Portals visual compatibility.
- Added a new Portal Gun inspired end-frame portal visual style.
- Added Random Rift portal generation with configurable attempts.
- Added new portal shot sound effects.
- Fixed unloaded local exits by improving portal preparation handling.
- Improved portal rendering performance and shader compatibility.

## Details

### Portal Transit and Reliability

- Fixed unloaded local exits by deferring preparation until the exit is ready.
- Improved portal readiness handling for distant destinations.

### Immersive Portals Visual Compatibility

- Added optional Immersive Portals visual compatibility.
- Fixed visual orientation and recursive cover handling.
- Improved compatibility rendering updates.

### Portal Visuals and Rendering

- Added the Portal Gun inspired end-frame portal visual style.
- Improved GPU portal rendering behavior.
- Improved shader compatibility with safer fallback pipelines.
- Optimized geometry paths and unnecessary render updates.

### Random Rift

- Added Random Rift portal opening behavior.
- Added configurable random rift attempts.

## Requirements

- Minecraft `26.1.2`
- NeoForge `26.1.2.95+`
- Java `25`

The same Rift Gun version must be installed on both the client and server.

There are no required runtime dependencies other than NeoForge. JEI and
Immersive Portals integrations are optional and are not bundled in the release
JAR.

## Known Issues

- Portal appearance may vary when using shader packs.

## Upgrading

Back up worlds before updating.

Existing destinations, player permissions, and configuration files are
compatible with this release.
