# Rift Gun 0.1.1-r1 — Minecraft 1.21.1

- Released: 2026-08-23
- Previous: 0.1.0-rc.1
- Platform: Minecraft 1.21.1, NeoForge 21.1.140+, Java 21
- Artifact: `riftgun-1.21.1-v0.1.1-r1.jar`

Rift Gun 0.1.1-r1 is a polish and compatibility release for Minecraft 1.21.1,
focused on improved portal visuals, rendering stability, Immersive Portals
visual compatibility, and fixes discovered after the 0.1.0 release candidate.

This release continues the multi-version codebase introduced in 0.1.0-rc.1,
with Minecraft 26.1.2 maintained alongside 1.21.1 from the same shared codebase.

## Highlights

- Added optional Immersive Portals visual compatibility.
- Added a new Portal Gun inspired end-frame portal visual style.
- Added Random Rift portal generation with configurable attempts.
- Added new portal shot sound effects.
- Fixed distant same-dimension teleports failing when the destination area was
  not loaded.
- Improved portal rendering performance by reducing unnecessary updates.
- Improved shader compatibility and fallback rendering paths.
- Polished portal frames, vortex motion, and visual effects.

## Details

### Portal Transit and Reliability

- Fixed an issue where same-dimension portals could fail when travelling to a
  distant unloaded destination.
- Improved portal readiness handling so transit no longer depends on stale
  preparation state.
- Improved deferred portal exit handling.

### Immersive Portals Visual Compatibility

- Added optional Immersive Portals visual compatibility.
- Immersive Portals is only used as an additional visual renderer. Rift Gun
  continues to control portal lifecycle, fuel, permissions, destination
  handling, entity relocation, and transit logic.
- Fixed visual orientation and recursive portal cover issues.

### Portal Visuals and Rendering

- Added the Portal Gun inspired end-frame portal visual style.
- Added vortex-style portal frame motion.
- Reduced excessive portal glow intensity.
- Improved geometry rendering performance and shader-safe fallback behavior.

### Random Rift

- Added Random Rift portal opening behavior.
- Added configurable random rift attempts.
- Improved random rift state handling and preparation cleanup.

## Requirements

- Minecraft `1.21.1`
- NeoForge `21.1.140+`
- Java `21`

The same Rift Gun version must be installed on both the client and server.

There are no required runtime dependencies other than NeoForge. JEI,
RyoamicLights, and Immersive Portals integrations are optional and are not
bundled in the release JAR.

## Known Issues

- Portal appearance may vary when using shader packs.

## Upgrading

Back up worlds before updating.

Existing destinations, player permissions, and configuration files are
compatible with this release.
